# Dusk Blue, The networks of the unseen — Exhibition Website

The official website for **Dusk Blue, The networks of the unseen**, a WIP2 exhibition by
MFA Computational Arts students at **Goldsmiths, University of London**.

The site is the exhibition's main public-facing platform: it presents the curatorial
concept and gives each participating artist their own page.

## About the exhibition
- **Title:** Dusk Blue, The networks of the unseen
- **Institution:** Goldsmiths, University of London
- **Type:** Work-in-Progress show
- **Dates:** 11th June
- **Website live:** 14th June

## What's on the site
- Curatorial concept / introduction to the exhibition
- An individual page for each of the 12 participating artists
- About page 

## How to run locally
Open `index.html` in any modern browser.
(Keep all asset folders — images, fonts, pages — alongside the HTML files.)
